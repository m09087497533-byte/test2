Исправление прокрутки для вашей присланной версии SceneMix — Фото+2.

1. Закройте приложение.
2. Откройте Install-Mac.command. При блокировке macOS: правая кнопка → Открыть.
3. В окне выбора укажите Start-Mac.command, которым вы обычно запускаете программу.
4. Установщик сохранит предыдущий main.py и заменит его исправленным файлом.
5. Запустится выбранная программа. В заголовке и над картинками будет «Фото+2».

Можно установить вручную: заменить main.py рядом с вашим Start-Mac.command
и заново запустить приложение.

Над картинками колесо мыши / трекпад прокручивает варианты по горизонтали.
Двойной щелчок по картинке открывает крупное превью.
В остальной области окна работает вертикальная прокрутка.
Предпросмотры имеют постоянную высоту, кнопки выбора остаются видимыми.

Изменён только интерфейс в main.py вашей версии.
Проверки не запускались по вашей просьбе.
