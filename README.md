# SceneMix — единый настольный редактор

Объединяет логику двух присланных программ: озвучка → сцены с таймкодами →
смысловой поиск → чередование фото и видео → монтаж с исходной озвучкой.
Интерфейс на русском, Python/Tkinter, сборка через FFmpeg.

## Что сделано

- Фото из веб-поиска, стоковые клипы Pexels/Pixabay, поиск YouTube и веб-видео.
- Схемы **фото / стоки**, **фото / стоки / фото / YouTube**,
  **фото / стоки / фото / интернет**, а также только фото или только стоки.
- Можно изменить источник отдельной сцены, написать свой запрос, назначить
  локальный файл или добавить ссылку на поддерживаемый yt-dlp сайт.
- Fast-gen строит поисковый запрос с учётом текста сцены и соседних реплик.
  Без его ключа используется перевод; готовый английский запрос можно ввести вручную.
- Для YouTube/веб-видео: поиск начала фрагмента по совпадению слов в доступных
  русских/английских субтитрах, ручной таймкод, загрузка нужного интервала.
- Фото плавно приближаются/отдаляются; видео обрезается или зацикливается.
  Паузы между репликами заполнены предыдущей сценой, до первой реплики — первой
  сценой, после последней — последней. Озвучка сохраняется целиком.
- Настраиваемое затемнение между сценами (не перекрёстное растворение),
  горизонтальный/вертикальный формат, прожиг субтитров.
- Автосохранение, продолжение подбора, остановка между операциями,
  до пяти попыток загрузки разных кандидатов на сцену.
- Экспорт MP4, отдельного SRT и JSON со ссылками на источники.

## Установка

Нужен **Python 3.11+**, **FFmpeg / ffprobe** в PATH и графический рабочий стол.
На Linux также нужен `python3-tk`; на Windows Tkinter обычно входит в установщик Python.
На macOS используйте Python с поддержкой Tk. Tesseract необязателен: он включает
дополнительную OCR-проверку водяных знаков на фото.

Windows (PowerShell):

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe main.py --doctor
.venv\Scripts\python.exe main.py
```

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
cp .env.example .env
.venv/bin/python main.py --doctor
.venv/bin/python main.py
```

Запускайте из распакованной папки. Готового `.exe` в архиве нет.
`requirements.lock.txt` фиксирует проверенные версии; `requirements.txt` задаёт
диапазоны для дальнейших обновлений. Если YouTube меняет протокол, обновите yt-dlp:
`python -m pip install --upgrade yt-dlp` в этом виртуальном окружении.

В `.env` укажите:

- `FASTGEN_API_KEY`: транскрибация и LLM-запросы, как в исходных программах.
- `PEXELS_API_KEY` и/или `PIXABAY_API_KEY`: хотя бы один для стоков.

Ключи не нужны для локального монтажа и импорта SRT/VTT.
Не публикуйте `.env` вместе с проектом. TLS-проверка включена.

## Работа

1. **Открыть озвучку**: MP3/WAV/M4A/AAC/FLAC/OGG.
2. **Транскрибировать** через ваш Fast-gen либо **Импорт SRT / VTT**.
   Для Fast-gen сохранён лимит исходной интеграции: 25 МБ входного аудио.
3. Выберите схему и нажмите **Применить схему**. Существующие назначения
   сохраняются; для их замены используйте **Снять назначение** у нужной сцены.
4. **Подобрать все пустые сцены** выполняет поиск и загрузку автоматически.
   Внешние видео загружаются, если включено поле о праве использования материалов.
5. Чтобы скорректировать подбор, выберите сцену, источник и нажмите **Найти**.
   Поле запроса можно оставить пустым либо вписать конкретные имена, место, эпоху.
   Выберите вариант, проверьте его через **Открыть источник**, затем назначьте.
6. Для YouTube/веб-кандидата можно нажать **Таймкод по субтитрам**
   или ввести секунды начала вручную. **Назначить найденное** скачает оттуда
   фрагмент на длительность реплики. При монтаже он продлевается на паузу, если нужно.
7. **Свой файл** назначает фото/видео с компьютера. Поле начала и кнопка
   **Сохранить начало** задают смещение внутри этого файла.
   Для уже скачанного внешнего фрагмента это смещение внутри фрагмента;
   чтобы изменить начало в исходном ролике, выберите кандидат и скачайте заново.
8. **Открыть файл** открывает выбранный файл системным просмотрщиком.
9. Выберите формат, длительность затемнения, субтитры и **Собрать видео**.

Результат: `<имя_озвучки>_project/final_video.mp4`, рядом `.srt` и `.sources.json`.
Проект — `project.json`, загруженные файлы — `media/`.
Снова откройте ту же озвучку, чтобы продолжить работу. Файлы старых редакторов
с полем `footage_path` читаются; относительные пути и перенесённые медиа проверьте
вручную. Рекомендуется сохранить копию старой папки проекта перед открытием.

Сборка останавливается с понятной ошибкой при отсутствующих файлах, неправильных
таймкодах или повреждённых клипах; чёрные заглушки автоматически не подставляются.
Повторный рендер заменяет готовый MP4 только после проверки результата.

## Что означает «по смыслу»

LLM формулирует запрос по озвучке и контексту. Поисковики возвращают кандидаты
по этому запросу. Таймкод внешнего видео выбирается по словам в субтитрах.
Программа **не анализирует изображение каждого кадра** и не гарантирует,
что первый результат визуально точно соответствует рассказу. Если субтитры
недоступны или совпадений нет, автоподбор явно пишет в журнал, что берёт начало
ролика; это место стоит проверить вручную. Водяные знаки отфильтровываются,
но это не определяет права использования: ссылки сохраняются для проверки.

YouTube/сайты могут ограничивать загрузку, требовать вход или менять протокол.
Программа сообщает об ошибке; можно выбрать другой источник или свой файл.
Автоматический обход ограничений доступа не реализован.

## Проверки и пример

```bash
python -m unittest discover -s tests -v
python tests/smoke_render.py /tmp/scenemix-demo
python main.py --render /tmp/scenemix-demo/demo.wav
```

На Windows укажите свой путь вместо `/tmp/scenemix-demo`.
Smoke-тест генерирует искусственные фото, клип и аудио, собирает оба формата,
проверяет цвета кадров/порядок сцен, паузы, зацикливание и аудиодорожку.
Это технический пример, не образец художественного стиля канала.

Поддерживаются `--doctor`, `--render AUDIO`, `--autopick AUDIO` для запуска без GUI.
`--render` и `--autopick` используют ранее сохранённый проект рядом с аудио.

В облачной проверке прошли установка зависимостей, запуск и проверка окна
Tkinter на виртуальном дисплее, тесты логики и реальные смешанные рендеры.
API-транскрибация и Pexels/Pixabay не проверены на живых ключах:
ключей в среде нет. YouTube и веб-поиск в этой среде недоступны по сети.
Ролик https://www.youtube.com/watch?v=hG6rytP9qFU не удалось просмотреть,
поэтому точное соответствие его стилю не подтверждено. Для такой настройки
нужен доступный видеофайл-пример и фрагмент вашей озвучки.
